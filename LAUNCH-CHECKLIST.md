# Launch & Maintenance Checklist

## Before public promotion
- [ ] Confirm GitHub Pages is publishing from `main` / root.
- [ ] Open the live site on mobile and desktop.
- [ ] Test every navigation item.
- [ ] Test every external source link.
- [ ] Confirm the independent-resource disclaimer is visible.
- [ ] Check the verification date in `SOURCES.md`.
- [ ] Confirm no experimental feature is described as production-ready.

## When the project changes
- [ ] Re-check primary sources.
- [ ] Update `SOURCES.md`.
- [ ] Update the research guide if a claim changed.
- [ ] Run a local static-server check.
- [ ] Open the live Pages URL after publishing.
