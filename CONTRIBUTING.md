# Contributing

Thanks for helping improve this independent Quantumnet resource.

## What to contribute

Useful contributions include:

- factual corrections
- clearer explanations
- better diagrams
- accessibility improvements
- mobile UX improvements
- links to newly published official documentation
- reproducible test observations
- terminology corrections

## Source-first rule

For technical claims about Quantumnet, prefer primary sources:

1. Official Tezos Spotlight announcements
2. Official Octez & Protocol documentation
3. The Tezos/tezos GitLab repository and its issues/MRs

If a statement is uncertain, label it as an observation or open question rather than presenting it as fact.

## Important distinction

This repository is independent. A pull request here does not automatically constitute a contribution to Tezos/Octez.

For contributions to Octez itself, follow the official contribution documentation and repository workflow.
