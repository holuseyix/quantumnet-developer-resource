# Contributing

Thanks for helping improve this independent Quantumnet resource.

## Useful contributions

Good contributions include:

- factual corrections
- clearer technical explanations
- accessibility improvements
- mobile UX improvements
- better diagrams or information architecture
- links to newly published official documentation
- reproducible observations from public test environments
- terminology corrections
- broken-link reports

## Source-first rule

For technical claims about Quantumnet, prefer:

1. [Tezos Spotlight](https://spotlight.tezos.com/)
2. [Octez & Protocol documentation](https://octez.tezos.com/)
3. [Tezos/tezos GitLab](https://gitlab.com/tezos/tezos)

When a statement cannot be verified, mark it as an observation, hypothesis, or open question.

## Independent-project boundary

This repository is independent. A pull request here does not automatically constitute a contribution to Tezos or Octez.

For contributions to Octez itself, follow the current official contribution documentation and repository workflow.

## Pull requests

Please keep changes focused and explain:

- what changed
- why it changed
- which primary source supports a technical claim
- whether the change is an observation or an established fact

Avoid presenting experimental behavior as production-ready functionality.

## Content quality

Before opening a PR:

- check links
- check mobile layout
- check keyboard navigation
- avoid unsupported technical claims
- preserve the independent-resource disclaimer
- update `SOURCES.md` if the factual basis changes
